# DZ. — Digital Realm

Uma página para reunir meus projetos de web design e desenvolvimento em um só lugar.

O visual combina referências de menus de jogos do primeiro PlayStation com uma ambientação egípcia, vídeo em loop e efeitos de tela CRT.

## Projetos

- **POP21** — site de entretenimento, música e eventos.
- **Allana Chaves** — experiência digital para consultas de tarot.
- **Oráculo da Angel** — site de apresentação de serviços e consultas.

## Executar localmente

Abra `index.html` com um servidor local, como o Live Server do VS Code. Não há etapa de instalação ou build.

## Estrutura

- `index.html` — página, estilos e interações.
- `assets/` — vídeo de fundo, imagem de capa e foto de perfil.
